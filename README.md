# Personal Website
## Background and Motivation
This website was inspired by observing some of my graduate classmates and Professors. I initially used a lanyon template due to Mark Otto, which gave me a good understanding of GitHub pages and the functionality of such websites. After this "tutorial", I decided to try building it (more or less) from scratch with a minimal design. The inspiration for such a change came from <a href="https://vel.bio">vel.bio</a>, <a href="https://mechanize.work">mechanize.work</a>, and again some faculty members at ECE U of T.

## Purpose
The general purpose of this website is to provide a sandbox in which I have control over the structure, content, and distribution of content, as opposed to other platforms like LinkedIn and GitHub. Currently, the content of the site is limited to blog/essay writing and project descriptions.
